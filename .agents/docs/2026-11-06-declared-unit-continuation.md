# Declared units and live continuation identities

This record describes the source group under review. The public dependency
versions have not yet been advanced to this ABI.

`owned_unit::retire` seals admission and takes an explicit `program` from
`self` or `describe`. Both id and birth identify a still-live continuation.
A helper may outlive the publisher that started it, so its previous numeric
unit is not a sufficient return location. The build owner is an appropriate
continuation when it remains alive through retirement. An expired identity,
an inaccessible destination or a different native session yields unknown.
Migration does not authorize termination or admission into the continuation.

`unit_observer` retains the original native observation reference. Its public
surface contains observation and lifetime operations only; native controls
and the native job are private. A compile-failure consumer verifies that it
cannot be supplied as a declared spawn unit or used to terminate a unit.
The C ABI observe/close restriction is a caller precondition on systems whose
unit is a numeric group, rather than a kernel-enforced read-only handle.

The source tests use the existing directory-local blocking IPC transport.
The native consumers measure paired startup and listener start/stop samples,
retain outliers, and test sealed admission after both unknown and successful
retirement. Three native source builds are required; cross-compilation alone
does not qualify native lifetime behavior or cost.

## 2026-11-06 dependency-group preparation

The final source group names OpenKal 0.24, Linux 0.25, macOS 0.22, Windows
0.20 and Emscripten 0.13. OS 0.3.0 uses platform 0.24 for its hosted and
image consumers. Its public manifest is advanced only after the lower source
archives and index entries are available. Native source controls establish
API behaviour; the final complete package CI and ordinary public resolution
remain separate qualification gates.
